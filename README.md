# C64-BASIC-Sammlung

Kleine Programme für den Commodore 64 (BASIC V2), die ich in den Achtzigern geschrieben habe. Abgetippt von meinen Ausdrucken.

| Datei | Was es tut |
|---|---|
| `zinsrechner.bas` | Zinseszins pro Jahr ausrechnen |
| `lotto.bas` | Tipp für Swiss Lotto (6 aus 42 plus Glückszahl) |

Laden im Emulator (VICE) oder mit `petcat -w2 -o prg.prg -- datei.bas` in ein PRG umwandeln.
